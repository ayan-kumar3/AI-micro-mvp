# Unread — What did I miss?

Unread is a Gemini-powered hackathon MVP for catching up on long group conversations. Paste chat text to find a concise overview, important messages, requests and commitments, likely decisions, deadlines, and direct name mentions.

## Run locally

1. Create a new Google AI Studio key. Revoke any key previously pasted into a chat or committed to a repository.
2. Copy `.env.example` to `.env.local` and replace the placeholder with your new key:

```dotenv
GEMINI_API_KEY=your_new_google_ai_studio_key
```

3. Start (or restart) the app so Next.js loads the server environment:

```bash
npm install
npm run dev
```

Open the local URL shown by Next.js. The Gemini API key is read only by the server and must never use a `NEXT_PUBLIC_` prefix.

## Deploy to Vercel

1. Push this project to a GitHub repository. Ensure `.env.local` is not committed; it is ignored by Git.
2. Import the repository in Vercel and deploy it as a Next.js project.
3. In the Vercel project, open **Settings → Environment Variables** and add `GEMINI_API_KEY` with a newly rotated Google AI Studio key. Do not use a `NEXT_PUBLIC_` prefix.
4. Enable the variable for the Production environment (and Preview if needed), save it, then redeploy so the server route can read it.
5. Verify the deployed site by analyzing the sample conversation.

## Use

1. Paste conversation text into the input, or select **Try sample**.
2. Or choose one of the short suggested examples in the preview panel.
3. Optionally enter your name to match exact name and `@mention` references. The sample fills in `Aisha` if the name field is blank.
4. Select **Catch me up**. The server sends the conversation and optional name to the Google Gemini API, then returns structured analysis to the app.
5. Use the results sidebar to jump among the summary, highlights, priority, action items, decisions, deadlines, mentions, and original chat. Category selection updates the matching highlights; on mobile the sidebar becomes a horizontal, scrollable category bar.
6. Inspect original messages, mark tasks complete, copy the summary or tasks, or export a plain-text report.
7. Select **Reset** to clear the conversation and its current results.
8. Choose **Moss**, **Amethyst**, or **Tide** in the header to change the color theme. The selected appearance is saved in browser-local storage.

The interface uses short, low-motion transitions to make loading, result entry, and source-message navigation easier to follow. Motion is reduced when the operating system's **Reduce motion** preference is enabled.

Unread accepts WhatsApp-exported lines (for example, `10/09/26, 9:02 AM - Sender: message`), bracket-timestamped lines such as `[9:02 AM] Sender: message`, and plain `Sender: message` lines. Wrapped lines are joined to the preceding message. Unidentified lines are retained as messages instead of being dropped. The input is limited to 30,000 characters and analysis handles up to 1,000 messages; if a conversation exceeds that limit, the app tells you that only the first 1,000 were analyzed.

## Privacy and API key

The app sends the pasted conversation and optional name to Google Gemini through the server-side `/api/analyze` route. Review Google's API terms and data-handling settings before using real or sensitive conversations. Unread does not persist chat text or results in its own database or browser storage. The API key is kept in `.env.local`, is excluded from source control, and is never sent to the browser. Only the color theme is saved in browser storage; report export and clipboard use are user-triggered.

The scaffold's remote Google font dependency was removed; the interface uses system fonts. As with any web app, hosting and loading the application itself requires access to its host, but conversation contents are not included in those requests.

## How the analysis works

`src/app/api/analyze/route.ts` sends parsed messages to Gemini 3.5 Flash-Lite and validates its structured JSON response before showing it. Findings refer back to source-message indexes so the UI can link each item to its original message. Results are capped at 1,000 messages and 30,000 input characters; the app reports when a conversation exceeds the message cap. Relative dates such as “tomorrow” remain relative; no calendar date or timezone is guessed.

AI output can miss sarcasm, implied tasks, unusual phrasing, indirect references, and context that spans several messages. Review original messages before acting on an extracted item.
